# UX y diseño — Ángel y Daniel

Ángel y Daniel son responsables de UX, diseño visual y frontend. Aquí se mantienen los flujos, wireframes, tokens y referencias visuales de ORIVIA.

- `tokens/`: colores, tipografías, espaciado, radios y estados.
- `screens/`: referencias y composición de pantallas.
- `../components/`: componentes reutilizables del frontend.
- `../docs/ux/`: decisiones de accesibilidad y pruebas de usabilidad.

Los contratos de API se consultan en la documentación de la raíz y se coordinan con Sebas y Kevin. A 16 de octubre de 2026, autenticación/registro, resumen administrativo, sincronización de integración y lectura pública de trazabilidad tienen llamadas desde el frontend; la operación de lotes y la red del clúster siguen con datos locales de demostración. Consultar `docs/backend-integration.md` y `ESTRUCTURA_FRONTEND_ORIVIA.md` para no confundir funciones disponibles en el cliente con vistas realmente integradas.
