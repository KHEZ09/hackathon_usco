Reglas de seguridad

  • El frontend no guarda secretos ni llama PostgreSQL.
  • Un 401 limpia sesión; 403 significa permiso insuficiente.
  • La IA es de solo lectura y blockchain reporta evidencia verificable.
  • El refresh token se rota y el anterior deja de ser válido.
