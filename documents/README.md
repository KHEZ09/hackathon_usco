# Paquete de entrega ORIVIA

Esta carpeta contiene las fuentes editables de los entregables oficiales E01-E10.
El código ejecutable, las pruebas y la infraestructura permanecen en `backend/`,
`frontend/` e `infra/`. Los resultados marcados como PENDIENTE no se presentan
como éxitos: requieren una ejecución o evidencia adicional antes del cierre.

## Regla de evidencia

Cada afirmación de funcionamiento debe poder repetirse con el commit final, datos
sintéticos, dos roles y el caso CAC001 (100 kg recibidos, 80 kg producidos,
20% de merma, alerta sobre 15%).
