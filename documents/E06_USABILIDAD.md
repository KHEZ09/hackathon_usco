# E06 - Usabilidad y accesibilidad

## Guion de evaluación

Una persona externa, sin instrucciones paso a paso, debe completar:

1. Consultar un QR y decidir si un lote está disponible y verificado.
2. Como operador, registrar CAC001 y una transformación 100 -> 80 kg.

Registrar perfil, tiempo, éxito, errores espontáneos, dudas y dispositivo móvil.
Repetir después de una mejora y comparar el resultado.

## Preparación actual

La interfaz usa etiquetas en español, estados textuales, mensajes de error y
controles responsivos. El guion y el formulario de observación quedan aquí para
la captura oficial. La ejecución con una persona externa y la comparación antes/
después siguen PENDIENTES; no se presentan como realizadas.
